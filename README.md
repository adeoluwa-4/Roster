# Daily Roster

## What it does

Daily Roster is a basketball guessing game. Players get 10 tries to find the mystery NBA player using clues about the team, height, position, draft year, and nationality.

## What I built

I built the website, game screen, clue system, player data tools, tests, and database structure.
